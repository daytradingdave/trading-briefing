# Trading briefing (EUR/USD · XAU/USD)

- `python briefing.py daily` – dagbriefing (zondag: weekoverzicht)
- `python briefing.py weekly` – weekoverzicht
- `python briefing.py alert` – alert ±15 min voor high impact USD/EUR events
- `python briefing.py test` – testbericht naar Telegram
- Voeg `--dry-run` toe om het bericht alleen te printen.

Instellingen: kopieer `.env.example` naar `.env` (lokaal) of gebruik GitHub Secrets (automatisch).
